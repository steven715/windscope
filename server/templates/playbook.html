核心心法（五個比喻）
鐘擺理論

股價繞著價值中樞擺盪

像鐘擺一樣繞著「價值中樞」在兩側來回：貪婪時擺過頭（超買）、恐慌時擺過頭（跌破）。中樞＝月線。

系統：價值中樞＝月線 MA20；乖離 =（收盤−月線）/ 月線
牽狗理論

主人牽著狗散步

主人（大勢／年線）牽著狗（股價／日線）。狗會暴衝或落後，但總被繩子拉回主人身邊。看主人往哪走，別被狗騙。

系統：主人＝年線 MA240 斜率（大勢方向）；狗＝日線對月線的乖離
望遠鏡 vs 顯微鏡

先看方向，再驗內功

望遠鏡看大勢方向（技術面篩選）；顯微鏡看內功（基本面驗證價值是否真實）。底部判斷光靠技術不可能。

系統：望遠鏡＝趨勢三態；顯微鏡＝基本面（目前預留，無資料源）
順大勢、逆小勢

順慣性、逆情緒

順著大鐘擺的慣性（做多上升趨勢）；逆著小鐘擺（衝高不追、回調才進）。狗跑太快減倉、落後可加倉。

系統：大勢 UP 才做多；小勢超買→不追、回踩月線+企穩→關注建倉區
內功 vs 外功

出場綁基本面，不設技術止損

外功＝技術面／K線位置；內功＝基本面／財報。出場由「大勢轉向」或「內功轉壞」驅動，沒有固定 % 技術止損。

系統：出場綁 big_trend 轉 DOWN/FLAT、gate 轉 FAIL
四步決策流程
1技術篩選望遠鏡
大勢判定：月線／年線是否昂首向上？
✗走平／向下 → 判為震盪或下行，停止交易、關掉軟體去研究財報。
✓昂首向上 → 進第二步。
2基本面研究顯微鏡
內功驗證：價值提升是否真實？
✗虛假／莊家炒作／財務造假 → 迴避（疑似虛假支撐）。
✓業績增長／行業景氣／政策利好 → 進第三步。
3前瞻判斷空間評估
空間評估：鐘擺還能擺多遠？
✗接近估值上限／末期狂歡 → 迴避（沒空間了）。
✓初期爆發／慣性強大 → 進第四步。
4交易決策順大勢、逆小勢
時機抓取（逆小勢）：日線走到哪？
•日線衝高／最貪婪時 → 等待回調，狗跑太快就減倉，不追。
→日線回調到月線支點附近 → 看企穩信號：
  · 仍續跌／穿透價值中樞 → 防禦陷阱、等小鐘擺回擺（不能剛跌就買）。
  · 止跌回擺 → 執行買入。
執行買入 · 順應大鐘擺慣性 → 進「儀表盤模式」追蹤，持續評估加減倉／出場

趨勢提醒
  • 無固定 % 技術止損：出場綁「大勢轉向 / 內功轉壞」，不是跌幾 % 就砍——那是這套方法論沒有、也相悖的東西。

開盤前三件事（約 30 分鐘檢查清單）
① 匯率（5 分鐘）

台幣是外資的腳印

8:45 報價 vs 前日 16:00 收盤，升/貶超過 1 角(0.1) = 明顯。升值→外資錢進來、權值股有機會；貶值→外資匯出、今天別衝。再對照人民幣＋韓元是否同步。

系統：離岸 USDTWD 晨對晨 delta + 亞幣同步（規則 {{ rule_version }}）
② 期貨夜盤（10 分鐘）

看價差，但先扣除息

夜盤 vs 現貨，正/逆價差 ±100 點有方向。除息例外：6–8 月旺季本就逆價差 100–300 點，要扣除息點數。夜盤爆量(>1.5×)且價差擴大→大戶佈局。

系統：調整後價差 + 夜盤量比 + 外資未平倉
③ 關鍵分點（10 分鐘）

看金額不看張數

有名分點連買且量增→放觀察；轉賣→跳過。低檔連買=摸底、高檔連買=防出貨、盤整連買=吸籌。同分點兩邊都有量=對敲假量不碰；隔日沖買超明天多半賣、不追。

系統：外資動向 + 主力分點 + 股價位置（籌碼解讀三維度）
三條貫穿心法
  • 看異常 > 看漲跌：重點不是漲跌，是有沒有不對勁（美股大漲但夜盤沒動→台股相對弱、不追高）。
  • 匯率是外資的腳印：先看匯率才不會被新聞帶風向。
  • 值得觀察 ≠ 進場：除非站回月線否則不進場（外資大買但股價仍跌，當天照樣別追）。
  • 綜合收斂沒有公式：三件事掃完 → 心裡有個底 → 筆記本寫一句話（方向＋觀察標的＋進場條件）。
